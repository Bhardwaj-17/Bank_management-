OOP Bank Management System (Java Swing & Persistence)

This project is an object-oriented Bank Management System implemented using Java Swing for the frontend interface and pure Java for the backend logic. It uses Java Serialization (File I/O) for data persistence, allowing accounts and transaction history to be saved between sessions.

🚀 Features

The application supports two distinct user roles:

Customer (User) Features

Account Registration: Create new bank accounts.

Secure Login: Authenticate using an account number and PIN.

Transactions: Perform Deposits and Withdrawals.

Fund Transfer: Transfer money to other registered bank accounts.

Transaction History: View a detailed history of all personal transactions.

Administrator (Admin) Features

Admin Login: Secure access to the management dashboard.

Customer Overview: View a list of all registered customer accounts.

Full Transaction Log: Review every transaction (Deposit, Withdraw, Transfer) across the entire bank.

Account Management: Delete existing customer accounts.
